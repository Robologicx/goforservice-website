# GoForService Website Package

## Contents
- `index.html` — responsive public landing page
- `goforservice_landing_page.html` — same page under a descriptive filename
- `assets/goforservice-logo.png` — logo artwork cropped from the supplied welcome-screen screenshot
- `assets/customer-welcome.png` — welcome screen
- `assets/customer-login.png` — login screen
- `assets/partner-home.png` — partner dashboard
- `assets/partner-registration.png` — partner registration / role selection screen

## Deployment
Upload the contents of this folder to the document root for `www.goforservice.com` (or the hosting directory configured for the public website). Keep the `assets` folder alongside `index.html` so images load correctly.

## Configured platform links
- Android APK: https://github.com/Robologicx/goforservice-website/releases/download/1.1/app-release.apk
- Web app: https://www.app.goforservice.com/
- Admin portal: https://www.app.goforservice.com/admin/

The supplied screenshots are presentation assets; they do not connect the landing page to the app backend.
